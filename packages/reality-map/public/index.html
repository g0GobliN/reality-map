Common Problems

  • 🔄 Circular Dependency (Cycle): Module A needs B, and B needs A. It's like a "chicken and egg" problem that creates a tangled knot, making code fragile and hard to fix.
  • 🏝 Abandoned Island: Code that isn't connected to the rest of your app. No other folders are using it. If you don't need it anymore, it's safe to delete!
  • 📦 Giant Module: A folder with too many files or lines of code. It's harder to understand and should probably be split up.

What is "Level" (1, 2, 3...)?

This controls your "zoom level" in the project folders:

  • Low Level (1-2): Bird's eye view. Shows only the big main sections.
  • High Level (5+): Microscopic view. Shows deep sub-folders and individual files.

Pro Tips

  • Click a module to see what's inside.
  • Double-click to drill deeper into subfolders.
  • Hover over the red ! badge for specific diagnostic info.
